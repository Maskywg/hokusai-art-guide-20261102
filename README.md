# 北齋・一生畫不完的世界

繁體中文藝術導覽，包含葛飾北齋生平、日本藝文地位、西方藝術影響，以及小布施北齋館展板的中文翻譯。

- 水的表現：3幅
- 冨嶽三十六景：3幅
- 諸國名橋奇覽：3幅
- 江戶美人與役者：3幅

## 來源及權利

作品圖像取自 The Metropolitan Museum of Art Open Access，館方標示 Public Domain / CC0；個別作品的連結、典藏編號、年代與 Credit Line 見頁面及 artwork-records.json。首頁及分享圖採用《神奈川沖浪裏》，分享圖經版面裁切。

展板中譯依網站委託者2026年11月2日於小布施北齋館拍攝的解說牌整理。原始照片未納入網站或本儲存庫。中譯及說明見 translations.zh-Hant.json 與網頁；涉及藝術詮釋或編年異說時另予標明。

本網站為個人觀展延伸導覽，非美術館官方網站。歷史資料及延伸閱讀連結收錄於頁尾。
